# ML Cún Cưng Android v1.0

Ứng dụng thú cưng nổi dành cho Android 10 trở lên, ưu tiên Xiaomi Redmi 10 / Android 13.

## Chức năng

- Chú cún 2D nền trong suốt hiển thị trên ứng dụng khác.
- Kéo thả và tự chạy trên màn hình.
- Chạm để cún phản ứng, hiện lời động viên.
- Nhắc việc theo số phút.
- Thu âm giọng nói, nghe lại và hẹn cún phát.
- Chọn MP3/M4A/WAV, phát ngay hoặc hẹn giờ.
- Tự bật sau khi khởi động nếu người dùng cho phép.
- Hoạt động ngoại tuyến, không quảng cáo, không tải dữ liệu cá nhân lên mạng.

GitHub Actions sẽ kiểm tra lint, chạy unit test và build APK debug tự động.

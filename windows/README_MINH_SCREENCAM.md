# Minh ScreenCam v1.0

Mã nguồn Windows được đóng gói thành 5 tệp `minh-screencam-source-v1.0.part00.b64` đến `part04.b64` để giữ nguyên cấu trúc dự án và không ảnh hưởng ứng dụng Android đang có trong kho.

Workflow `Build Minh ScreenCam EXE` tự ghép và giải mã gói nguồn, build trên Windows, đóng gói FFmpeg, kiểm tra gói chạy, tạo bản Portable và bộ cài Inno Setup.

Sản phẩm build:

- `MinhScreenCam_Setup_v1.0.0.exe`
- `MinhScreenCam_v1.0.0_Portable.zip`
